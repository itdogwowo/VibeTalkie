# P1 ASR 基準測試集（20 句）
#
# 格式：`編號|參考文字`。`#` 開頭是註解，空行忽略。
# 參考文字就是「正確答案」，所以**不要**為了配合模型而改寫。
#
# 設計原則（依 plan.md §6 T4：「中文為主 + 英文/數字」）：
#   - 台灣用語與自然語序（不是書面語）
#   - 含標點，用來檢查標點是否正確產生
#   - 刻意混入英文縮寫、阿拉伯數字、國字數字
#   - 長度 10–25 字，接近實際「按住說話」的使用長度
#   - 涵蓋不同領域：日常、辦公、交通、餐飲、技術
#
